# CustomHooks

A small React demo project showcasing a collection of reusable custom hooks.

## Features

- Examples of custom hooks for managing component state and side effects  
- Simple, focused demos for learning and reuse  
- Vite-based setup for fast development and hot module replacement  

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/bofrank/CustomHooks.git
   cd CustomHooks
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open the URL shown in your terminal (usually `http://localhost:5173`) in your browser.

## Scripts

- `npm run dev` – Start the dev server  
- `npm run build` – Build for production  
- `npm run preview` – Preview the production build  

## Project Structure

- `src/` – React components and custom hooks  
- `public/` – Static assets  
- `index.html` – Entry HTML file  
- `vite.config.js` – Vite configuration  

## Requirements

- Node.js and npm (or pnpm / yarn)  
- Modern browser supporting ES modules
